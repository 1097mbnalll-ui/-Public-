# وين نروح؟ دليل السفر العربي

دليل سفر عربي. الوجهة الأولى فيتنام: المدن، الأماكن، السكن، الأسعار، الأكل الحلال، ومخطط رحلة يعطيك برنامج يوم بيوم مع التكلفة.

## تشغيله على جهازك

افتح `index.html` في المتصفح مباشرة، أو شغّل خادم بسيط:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الملفات

| الملف | وش فيه |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `data/vietnam.js` | **كل المحتوى**: المدن والأماكن والأسعار والمصادر |
| `assets/app.js` | الصفحات ومخطط الرحلة وتحويل العملات |
| `assets/style.css` | التصميم |

## تعديل المحتوى

كل شي في `data/vietnam.js`:

- **إضافة مكان:** انسخ أي عنصر من `places` داخل المدينة وعدّله. الأسعار بالدونق.
- **تحديث سعر الصرف:** عدّل `rates` وغيّر `date`.
- **كل رقم يحتاج مصدر:** حط `src` (اسم المصدر من `sources`) و`date` (تاريخ التحقق).

## النشر على GitHub Pages

من إعدادات المستودع: **Settings ← Pages ← Deploy from a branch**، واختر الفرع والمجلد `/ (root)`.
